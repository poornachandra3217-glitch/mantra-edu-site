
## ✨ Features
- **5 required pages:** Home, About, Courses, Gallery, Contact/Registration
- **Responsive design:** flexible grid layouts + CSS media queries for mobile, tablet and desktop
- **Basic SEO:** unique `<title>` and meta description/keywords per page, one `<h1>` per page, structured `<h2>`/`<h3>` headings, descriptive alt text on every image, simple file names
- **JavaScript features:**
  - Mobile hamburger navigation menu
  - FAQ accordion toggle on the Courses page
  - Registration form validation on the Contact page
- **Design system:** a custom "open notebook" visual identity (ruled-paper lines, hole-punch margin, highlighter-style headings, binder-tab navigation) — original design, not a template

## 🛠️ Tools Used
- HTML5, CSS3, vanilla JavaScript
- Google Fonts: Space Grotesk, Lora, JetBrains Mono
- No build tools required — it's a static site
